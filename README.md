# A Domain Check Tool

A simple Python tool that helps users look up a domain's IP address, compare DNS results, and check site avaliabilty.

I built this project to basic domain troubleshooting easier to understand.

## Features

- Finds IPv4 addresses associated with a domain.
- Finds IPv6 addresses if available.
- Compares results from your system DNS, Google DNS, and Cloudflare DNS.
- Checks whether the website responds to HTTP and HTTPS requests.
- Handles invalid domain input.

## Requirements

- Windows computer (for the packaged `.exe` release)
- An internet connection
- Python 3.10 or later
